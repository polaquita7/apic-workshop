¿Qué es el Portal de Desarrolladores?

Concepto clave: Developer Portal

El Portal de Desarrolladores es el portal web que permite generar comunidad con los desarrolladores de aplicaciones.

  • Socializar Productos y APIs
  • Registrar usuarios y aplicaciones consumidoras
  • Autogestión de suscripciones y credenciales
  • Revisar documentación y probar APIs
  • Realizar seguimiento de consumo
  • Compartir contenido, comunidades y foros

Pasos del laboratorio

Paso 1: Acceder al portal

1
Abrir el Developer Portal en una nueva pestaña

Abrí una nueva pestaña del navegador y navegá a la URL del Developer Portal de tu ambiente:

¿No tenés la URL? Podés encontrarla en el API Manager

En el API Manager, navegá a Manage → Sandbox → Catalog settings → Portal. Copiá la Portal endpoint URL que aparece ahí.

Paso 2: Crear una cuenta en el portal

2
Hacer click en "Crear cuenta"

En la página principal del Developer Portal, hacé click en el botón Crear cuenta (arriba a la derecha).

User Registries separadas

Las User Registries del API Manager y del Developer Portal son independientes. Tu usuario de APIM no sirve para loguearte en el portal. Tenés que crear una cuenta nueva específicamente para el portal.

3
Completar el formulario de registro

Completá el formulario con tu información. Usá una dirección de e-mail válida a la que tengas acceso, ya que vas a recibir un correo de activación.

Recordá tu contraseña

La vas a necesitar más adelante en este mismo laboratorio para loguearte y usar el portal.

Al confirmar el formulario, aparecerá un mensaje de confirmación indicando que se envió el e-mail de activación.

Paso 3: Activar la cuenta y loguearse

4
Activar la cuenta desde el e-mail

Revisá tu casilla de correo. Vas a recibir un mensaje del portal con el asunto Registro de cuenta de portal de desarrollador Sandbox. Hacé click en el enlace de activación que contiene el mail.

Al activar la cuenta, el portal te confirmará que podés iniciar sesión.

Paso 4: Crear una aplicación consumidora

Usuarios vs. Aplicaciones

El registro al portal es a nivel usuario: cada persona crea su propia cuenta. Pero la suscripción a un Producto es a nivel aplicación: las credenciales (API Key y Secret) se generan para la app, no para el usuario. Esto permite que una misma persona tenga múltiples apps con distintas suscripciones y credenciales. Al mismo tiempo, multiples desarrolladores pueden estar trabajando con la misma aplicación; pues pueden pertenecer a la misma organización consumidora

5
Iniciar la creación de la app desde la pantalla de bienvenida

Después de loguearte, el portal te dará la bienvenida con dos opciones. Hacé click en Create a new App.

6
Completar el formulario de la nueva aplicación

En el formulario Create a new application, completá el campo Title con el nombre de tu app:

Paso 5: Guardar el API Secret

7
Copiar y guardar las credenciales de la aplicación

Al crear la aplicación, el portal muestra el API Key y el API Secret. Guardá el Secret ahora, solo se muestra una vez.

Guardá el Secret antes de cerrar

Paso 6: Perspectiva del Proveedor

8
Verificar la app en la solapa Applications del catálogo

Volvé al API Manager y navegá a Manage → Sandbox → Applications. El proveedor de APIs usa esta vista para administrar todas las aplicaciones de los consumidores. Vas a ver tu aplicación app-ceci01 listada junto con las de los otros participantes del lab. Si tuvieramos habilitado un proceso de aprobación de suscripciones, se haría desde la solapa Tasks.

9
Verificar la solapa Consumers y Subscriptions

Revisá la solapa Consumers para ver tu organización de consumidor registrada. Luego revisá la solapa Subscriptions: en este momento debería aparecer vacía porque todavía no nos suscribimos a ningún Producto.

Paso 7: Explorar el portal

10
Explorar la solapa Apps del portal

Volvé al Developer Portal. Hacé click en Apps en el menú superior para ver tu aplicación app-ceci01.

Si hacés click en app-ceci01 y luego en la solapa Subscriptions, vas a ver que por el momento no tiene suscripciones activas.

11
Navegar a API Products en el portal

Hacé click en API Products en el menú superior. Vas a ver el Producto product-ceci01 que publicamos en el lab anterior. Podés pasar el mouse sobre la tarjeta para ver las APIs que incluye.

Paso 8: Suscribirse al Producto

12
Abrir el Producto y hacer click en Select

Hacé click sobre product-ceci01 en API Products. Se abre la página de detalle del Producto mostrando las APIs incluidas (catalog-ceci01) y los Plans disponibles. Hacé click en Select en el plan plan-ceci01 para iniciar el proceso de suscripción.

Plan de suscripción

Al suscribirte, elegís el Plan del Producto. El Plan define los límites de uso (rate limits, cuotas) que se aplicarán a las llamadas que tu aplicación haga a las APIs incluidas en ese Producto.

13
Wizard Subscribe, paso 1: seleccionar la aplicación

Se abre el wizard Subscribe to product-ceci01 1.0. Seleccioná tu aplicación app-ceci01 y hacé click en Next.

14
Wizard Subscribe, paso 2: confirmar suscripción

El paso Confirm Subscription muestra el resumen: Producto product-ceci01, aplicación app-ceci01 y plan plan-ceci01. Hacé click en Next.

15
Suscripción completada

El paso Subscription Complete confirma que tu aplicación está suscripta al plan. Hacé click en Done.

Si volvés a la solapa Subscriptions de tu aplicación app-ceci01, ahora vas a ver la suscripción activa a product-ceci01 con el plan plan-ceci01, junto con las credenciales (API Key) de la app.

Paso 9: Probar la API desde el portal

16
Navegar a la API catalog-ceci01 y revisar su documentación

Volvé a API Products → product-ceci01. Hacé click sobre la tarjeta de catalog-ceci01 para ver su documentación. Verás el endpoint, el protocolo y los métodos disponibles. En el panel izquierdo aparece el método GET /catalog-ceci01.

17
Usar Try it para enviar la petición

Hacé click en la pestaña Try it. Se muestra el método GET /catalog-ceci01 con su URL completa. Hacé click en Send.

Si todo está correcto, vas a recibir una respuesta 200 OK con el JSON del CatalogManager.

¡API probada con éxito!

Recibiste una respuesta 200 OK con los datos del backend. El flujo completo está funcionando: portal, suscripción, credenciales y llamada a la API a través del gateway.

Verificación

Al finalizar este laboratorio deberías poder:

  • Crear una cuenta de consumidor en el Developer Portal (distinta de la del API Manager).
  • Crear una aplicación consumidora con sus credenciales (API Key y Secret).
  • Verificar desde el API Manager que la app y el consumidor aparecen en el catálogo.
  • Explorar el catálogo de API Products en el portal: buscar, filtrar y revisar APIs y planes.
  • Suscribir la aplicación a un Producto publicado.
  • Probar la API desde el portal usando el API Secret de la aplicación y recibir una respuesta válida.
